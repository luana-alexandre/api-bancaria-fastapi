# API Bancária Assíncrona com FastAPI

Projeto desenvolvido como desafio prático do bootcamp da DIO em parceria com o LuizaLabs, com foco em desenvolvimento de APIs assíncronas utilizando FastAPI.

## Tecnologias utilizadas
- Python
- FastAPI
- SQLAlchemy
- SQLite
- Uvicorn
- JWT Authentication

## Funcionalidades
- Cadastro de usuários
- Autenticação com JWT
- Operações bancárias
- Estrutura de API assíncrona

## Como executar

Clone o projeto:

```bash
git clone https://github.com/luana-alexandre/api-bancaria-fastapi.git
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute a aplicação:

```bash
uvicorn main:app --reload
```

## 📌 Objetivo
Projeto criado para prática de desenvolvimento backend com FastAPI e APIs assíncronas durante o bootcamp da DIO + LuizaLabs.
